# 格式保留翻译功能使用指南

## 🎉 新功能概述

现在你的翻译工具支持**格式保留翻译**，能够在翻译 ePub 和 Markdown 文件时保持原始的文档结构和格式。

## ✨ 支持的功能

### 📚 ePub 格式保留
- **结构保持**: 保留章节、标题层级、段落结构
- **元数据保留**: 保持书籍标题、作者等信息
- **多格式输出**: 生成翻译后的 ePub 文件 + HTML 预览版本
- **智能解析**: 自动识别和处理 HTML 内容结构

### 📝 Markdown 格式保留
- **完整语法支持**: 标题、列表、引用、代码块等
- **结构保持**: 保持原始的 Markdown 层级结构
- **代码块保护**: 代码块内容不被翻译，保持原样
- **多格式输出**: 生成 Markdown + HTML + 纯文本版本

## 🚀 使用方法

### 1. 通过 Web 界面使用

1. 访问 `http://localhost:5001/epub-markdown`
2. 上传你的 ePub 或 Markdown 文件
3. 选择目标语言和翻译服务
4. 点击开始翻译
5. 下载格式保留的翻译结果

### 2. 支持的文件格式

- **ePub**: `.epub` 文件
- **Markdown**: `.md`, `.markdown` 文件  
- **文本**: `.txt` 文件

### 3. 输出格式

#### ePub 文件翻译后输出：
- `原文件名_translated_语言.epub` - 翻译后的 ePub 文件
- `原文件名_translated_语言.html` - HTML 预览版本
- `原文件名_translated_语言.txt` - 纯文本备份

#### Markdown 文件翻译后输出：
- `原文件名_translated_语言.md` - 格式保留的 Markdown 文件
- `原文件名_translated_语言.html` - HTML 预览版本
- `原文件名_translated_语言.txt` - 纯文本备份

## 🔧 技术特性

### 智能文本分块
- 自动识别可翻译内容（标题、段落、列表项等）
- 跳过不需要翻译的内容（代码块、特殊标记等）
- 保持原始格式标记和结构

### 格式重建
- **Markdown**: 完整重建原始 Markdown 语法
- **ePub**: 生成符合标准的 ePub 文件
- **HTML**: 提供美观的预览版本

### 错误处理
- 自动降级到纯文本保存（如果格式保留失败）
- 详细的错误日志和进度反馈
- 文件完整性检查

## 📋 示例

### Markdown 格式保留示例

**原始文件**:
```markdown
# 主标题

这是一个段落。

## 二级标题

- 列表项1
- 列表项2

> 这是引用

```python
print("代码不会被翻译")
```
```

**翻译后保持格式**:
```markdown
# Main Title

This is a paragraph.

## Secondary Title

- List item 1
- List item 2

> This is a quote

```python
print("代码不会被翻译")
```
```

### ePub 格式保留

- 保持原始章节结构
- 保留标题层级 (H1, H2, H3...)
- 维持段落和列表格式
- 生成可阅读的 ePub 文件

## ⚠️ 注意事项

1. **文件大小**: 大文件会自动分块处理，保持翻译质量
2. **编码支持**: 自动检测和处理多种文本编码
3. **错误恢复**: 如果格式保留失败，会自动生成纯文本版本
4. **资源占用**: ePub 处理需要更多内存和处理时间
