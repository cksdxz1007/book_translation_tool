## 问题排查指南

### 常见问题及解决方案

#### 问题1: 版本升级失败
**症状**: `uv tool install` 命令失败
**解决方案**:
- 检查网络连接
- 清理uv缓存: `uv cache clean`
- 尝试使用pip安装: `pip install BabelDOC==0.5.16`

#### 问题2: 配置解析错误
**症状**: TOML配置文件解析失败
**解决方案**:
- 验证TOML语法正确性
- 检查特殊字符转义
- 使用在线TOML验证工具

#### 问题3: 翻译性能下降
**症状**: 翻译时间显著增加
**解决方案**:
- 调整 `--pool-max-workers` 参数
- 优化 `--qps` 设置
- 检查网络延迟
- 验证API服务状态

#### 问题4: 内存使用过高
**症状**: 应用内存占用异常
**解决方案**:
- 启用 `--max-pages-per-part`
- 减少 `--pool-max-workers`
- 监控大文件处理
- 优化文件分块策略

#### 问题5: OCR功能异常
**症状**: 扫描文档处理失败
**解决方案**:
- 验证 `--auto-enable-ocr-workaround` 设置
- 检查OCR依赖项
- 测试不同扫描质量文档
- 调整OCR参数配置
